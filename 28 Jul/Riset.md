# Riset Topik: Mengenal Server Lokal dan Server Cloud

## Latar Belakang

Dalam proses belajar pemrograman, peserta umumnya langsung menggunakan berbagai tools seperti Jupyter Notebook, Visual Studio Code, Google Colab, atau layanan cloud tanpa memahami lingkungan tempat aplikasi tersebut berjalan. Padahal, pemahaman mengenai server lokal dan server cloud merupakan dasar yang penting sebelum mempelajari topik yang lebih kompleks, seperti database, API, deployment, maupun komputasi awan.

Topik **"Mengenal Server Lokal dan Server Cloud"** dipilih untuk memberikan pemahaman konseptual mengenai dua jenis lingkungan pengembangan yang paling sering digunakan. Dengan memahami perbedaannya sejak awal, diharapkan peserta tidak hanya mampu menggunakan suatu tools, tetapi juga memahami alasan di balik penggunaannya.

---

## Tujuan Riset

Riset ini dilakukan untuk:

- Mengidentifikasi konsep dasar server lokal dan server cloud.
- Mempelajari perbedaan karakteristik, kelebihan, dan kekurangan masing-masing.
- Mengumpulkan contoh penerapan server lokal dan server cloud dalam proses pengembangan perangkat lunak.
- Menyusun materi pembelajaran yang mudah dipahami oleh pemula.

---

## Alasan Pemilihan Topik

Topik ini dipilih karena:

- Masih banyak pemula yang belum memahami perbedaan server lokal dan server cloud.
- Istilah seperti *localhost*, *local server*, dan *cloud* sering muncul saat menggunakan berbagai tools pengembangan.
- Materi ini dapat menjadi penghubung sebelum mempelajari topik lanjutan seperti Jupyter Notebook, database, API, maupun deployment.
- Pembahasan bersifat umum sehingga relevan untuk berbagai bidang, seperti Data Analysis, Data Science, Machine Learning, maupun Software Development.

---

## Ruang Lingkup

Riset difokuskan pada pemahaman konsep dasar, meliputi:

- Pengertian server.
- Konsep server lokal.
- Konsep server cloud.
- Perbedaan keduanya.
- Contoh penggunaan dalam lingkungan pengembangan.

Pembahasan tidak mencakup konfigurasi server, administrasi sistem, maupun deployment aplikasi secara teknis.

---

## Hasil yang Diharapkan

Hasil dari riset ini adalah tersusunnya materi pembelajaran yang sederhana, sistematis, dan mudah dipahami oleh pembaca pemula sebagai bagian dari materi orientasi dan setup lanjutan.
